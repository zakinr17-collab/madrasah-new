# Game Arena V3 Visual Spec

Source of truth: visualisasi master terakhir yang disetujui user.

Prinsip:
- Tidak menggunakan asset Game Arena lama sebagai visual utama.
- Karakter, arena, kendaraan, struktur, obstacle, dan FX dibuat baru.
- Style chibi premium, vivid, outline bersih, proporsi kompak dan readable di HP.
- HUD navy glossy, border cyan, timer pill, health/team bar, pilihan jawaban putih dengan state hijau.
- Layout mengikuti komposisi visual master dan boleh ditingkatkan selama bahasa desain tetap sama.
- Logic gameplay/realtime, state dan endpoint tidak diubah.
- Responsif di HP, tablet, desktop.

Mode:
1. Tug War — schoolyard, spectator stand, flags, sandy field, rope center.
2. Base Battle — blue/red castle, school-festival battleground, cover crates, projectiles.
3. Battle Royale — top-down schoolyard/ruins, walls, bushes, rocks, crates, glowing loot.
4. Quiz Race — school stadium, horizontal track, four colorful karts, speed trails.
5. Laser Duel — neon sci-fi arena, blue/red armored chibi, central laser clash.
